Il sito non è riuscito ad avviarsi

Il browser non ha caricato l’applicazione. Quasi sempre significa che GitHub Pages sta pubblicando i file del progetto così come sono, invece del sito compilato.

Controlla queste tre cose:

  1. nel repository esiste il file .github/workflows/deploy.yml (è in una cartella nascosta: caricando i file a mano è facile dimenticarlo);
  2. in Settings → Pages, alla voce Source, è scelto GitHub Actions e non “Deploy from a branch”;
  3. nella scheda Actions l’ultima esecuzione è andata a buon fine (spunta verde).

Trovi la procedura completa nel file README.md del repository.
